📖 O que é cada coisa?

function nome() { }
Uma ação que o código sabe fazer. Começa com function, tem um nome, e tudo que ela faz fica entre { }.
function salvarMemoria() { }
localStorage
É onde o cérebro do projeto fica salvo no navegador. Mesmo fechando, os dados ficam lá.
fetch() / API / Gemini / OpenAI
É a parte que conversa com a IA. fetch faz uma chamada para a internet com uma chave secreta (apiKey).
import / export / require
São as conexões entre arquivos. Em código embolado isso pode estar quebrado e causar erros.
🚨 O que é vínculo Replit?
Partes do código que só funcionam dentro da Replit. Quando você para de pagar, o app para. Exemplos:

replit.com · /api/code-assistant · /api/tts · REPL_ID · REPLIT_DB
🐛 O que são bugs?
São erros no código que fazem ele não funcionar direito. Podem ser: chaves { } faltando, parênteses ( ) sobrando, variáveis com erro de digitação, ou funções sendo chamadas que não existem.
⚡ O que são conflitos de dependência?
Quando o projeto usa duas bibliotecas que brigam entre si, ou uma biblioteca que precisa de outra que não foi instalada. O botão "Detectar Conflitos" ajuda a encontrar isso.
📌 Para que serve a Triagem?
Você anota o que encontrou (linha X tem problema Y) e depois manda tudo para a IA analisar de uma vez. Perfeito para economizar créditos — você faz a triagem primeiro, depois resolve tudo de uma vez.
