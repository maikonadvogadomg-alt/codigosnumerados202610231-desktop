Aplicativo Desktop 100% standalone — Não tem NADA do Replit O SK Editor 4 é um editor de código profissional que roda no seu computador. Igual ao VS Code mas com terminal, preview e IA tudo num lugar só. Seus arquivos ficam no seu HD. Funciona sem internet.

Por que o preview aqui no Replit parece diferente?

⚠️ Isso é normal e correto Quando você abre este site no Replit, está vendo o app rodando nos SERVIDORES DO REPLIT. É só para você ver como ficou antes de baixar. O executável .exe do seu PC é diferente: roda localmente, terminal real, preview local — sem depender de ninguém.

👁 Preview — Como Usar Corretamente

Como o Preview funciona no executável .exe O preview não é uma URL da internet. É um proxy local que redireciona para 127.0.0.1:PORTA do seu próprio computador. Isso significa que seu app roda 100% no seu PC.

Como abrir o Preview:

1
Rode npm run dev no terminalO servidor de desenvolvimento inicia no seu PC
2
O SK Editor detecta a porta automaticamenteQuando aparecer "Local: http://localhost:5173" no terminal, o editor reconhece
3
O painel de Preview já abreÀ direita do editor, o seu app aparece carregado
4
Salve um arquivo → Preview atualiza sozinhoHot reload: edite o código, salve com Ctrl+S, veja a mudança em segundos

Preview não abriu automaticamente?

1
Veja a porta no terminalProcure por "localhost:XXXX" ou "port XXXX" na saída do comando
2
Clique no botão de Preview manualmenteBotão 👁 na barra superior do editor
3
Digite a porta manualmenteCampo de URL no painel de preview — coloque http://localhost:5173

📱 APK Android via Capacitor

O que é Capacitor? Capacitor é uma ferramenta que pega seu app web (React, Vue, HTML) e transforma em um APK real para Android. Você escreve uma vez em web e gera o APK.
⚠️ Precisa de Android Studio instalado no seu PC O Android Studio é gratuito e necessário para gerar o APK. Baixe em: developer.android.com/studio (~1GB)

Passo a passo — Do projeto web ao APK:

Etapa 1 — Instalar o que precisa (no terminal do SK Editor):

npm install @capacitor/core @capacitor/cli @capacitor/android

Etapa 2 — Inicializar o Capacitor:

npx cap init "Nome do App" "com.seunome.seuapp" --web-dir dist

Substitua: "Nome do App" pelo nome real e com.seunome.seuapp pelo ID único do app (sem espaços).

Etapa 3 — Adicionar plataforma Android:

npx cap add android

Etapa 4 — Gerar build do seu app:

npm run build

Etapa 5 — Copiar para o Capacitor:

npx cap copy android

Etapa 6 — Abrir no Android Studio:

npx cap open android

O Android Studio abre automaticamente com o projeto.

Etapa 7 — Gerar o APK no Android Studio:

1
Menu Build → "Build Bundle(s) / APK(s)" → "Build APK(s)"
2
Aguarde o build (2-5 min)
3
Clique em "locate" no toast que apareceO APK fica em: android/app/build/outputs/apk/debug/app-debug.apk
4
Transfira o .apk para o celular e instaleVia cabo, WhatsApp, Google Drive ou email

Arquivo capacitor.config.json (gerado automaticamente):

{
  "appId": "com.seunome.seuapp",
  "appName": "Nome do App",
  "webDir": "dist",
  "server": {
    "androidScheme": "https"
  }
}

Instalar APK no celular Android:

1
Ative "Instalar apps desconhecidos" no AndroidConfigurações → Segurança → Fontes desconhecidas → Ativar
2
Transfira o APK para o celularVia cabo USB, Drive ou WhatsApp para você mesmo
3
Abra o arquivo no celular e clique "Instalar"

🔧 Problemas Comuns e Soluções

App não abre — Windows bloqueou:

Solução A: Clique com botão direito no SK-Editor-4.exe → Propriedades → marque a caixa "Desbloquear" → OK → abra

Solução B: Na tela do SmartScreen → clique "Mais informações" → "Executar assim mesmo"

Terminal não encontra npm / node:

Instale o Node.js em nodejs.org → após instalar, feche e abra o SK Editor de novo. O terminal precisa ser reiniciado para reconhecer os novos programas.

Preview não abre automaticamente:

1. Rode npm run dev no terminal primeiro

2. Olhe a porta que aparece (ex: "localhost:5173")

3. No painel de preview, clique no botão 👁 e coloque a URL manualmente: http://localhost:5173

Preview mostra tela em branco:

O servidor ainda não iniciou. Aguarde o terminal mostrar "ready" ou "Local: http://localhost:XXXX" e então atualize o preview (F5 no painel de preview).
