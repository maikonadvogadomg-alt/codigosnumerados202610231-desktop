📖 Guia de Uso

🔌 O que é Proxy em Cascata?

É uma técnica onde você tenta chamar a API através de múltiplos servidores intermediários (proxies). Se um falhar, tenta o próximo automaticamente.

Vantagens:
• Aumenta confiabilidade
• Contorna bloqueios geográficos
• Gratuito
• Sem limites de requisições

🌐 Proxies Gratuitos

Este testador usa proxies públicos gratuitos:
• cors-anywhere.herokuapp.com
• api.allorigins.win
• proxy.cors.sh
• thingproxy.freeboard.io

🧪 Como Testar sua API

1. Coloque a URL da API
2. Escolha o método (GET, POST, etc)
3. Adicione headers e body se precisar
4. Marque "Usar Proxy em Cascata"
5. Clique em "Testar API"

⚖️ Para Seu Projeto Jurídico

Use o Playground para testar a IA Groq:
1. Coloque sua chave de API Groq
2. Digite uma pergunta jurídica
3. Veja a resposta em tempo real
4. Copie o código para seu projeto

⚠️ Limitações

• Alguns proxies têm limite de requisições
• Alguns podem estar offline
• Use em desenvolvimento, não em produção
• Para produção, use um proxy pago ou sua própria API
