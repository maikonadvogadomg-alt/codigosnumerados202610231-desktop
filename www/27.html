Como o app funciona (sem servidor)

  • Chama a IA diretamente do celular — sem servidor próprio
  • Salva histórico no próprio celular (AsyncStorage)
  • Opcionalmente sincroniza com o banco Neon (PostgreSQL na nuvem)
  • Não depende do Replit para funcionar

Passo a passo para gerar o APK

1. Instale o Node.js no seu computador (se não tiver)

Acesse https://nodejs.org → baixe a versão LTS → instale normalmente.

2. Abra o Terminal

  • Windows: pressione Win + R, digite cmd, Enter
  • Mac: abra o Spotlight e procure "Terminal"

3. Entre na pasta do projeto

Descompacte o ZIP e navegue até a pasta:

  • Windows: cd %USERPROFILE%\Desktop\assistente-juridico
  • Mac/Linux: cd ~/Desktop/assistente-juridico

4. Instale as dependências

bash
npm install

Aguarde terminar (1-2 minutos).

5. Configure o token

Mac/Linux:

bash
export EXPO_TOKEN=Jqn3oZYPovCelKuLh0WeXUulKQTNe_6FNhqossqv

Windows (CMD):

cmd
set EXPO_TOKEN=Jqn3oZYPovCelKuLh0WeXUulKQTNe_6FNhqossqv

Windows (PowerShell):

powershell
$env:EXPO_TOKEN="Jqn3oZYPovCelKuLh0WeXUulKQTNe_6FNhqossqv"

6. Inicialize o git (necessário uma vez)

bash
git init
git add .
git commit -m "build"

7. Gere o APK

bash
npx eas build --platform android --profile preview --non-interactive
  • Leva 5 a 10 minutos na nuvem da Expo
  • No final aparece um link para baixar o APK
  • Você também pode acompanhar em:

https://expo.dev/accounts/maikons-individual/projects/assistente-juridico/builds

8. Instale no celular

  1. Baixe o APK pelo link
  2. Envie para o celular (WhatsApp, Drive, email ou cabo USB)
  3. No celular: Configurações → Segurança → Fontes desconhecidas → Permitir
  4. Abra o arquivo APK e instale

9. Configure no celular (primeira vez)

  1. Abra o app
  2. Vá na aba ⚙️ Config.
  3. Cole sua chave de API (Groq, Gemini, OpenAI, etc.)
  4. Opcionalmente cole a URL do Neon para salvar histórico na nuvem
  5. Toque em Salvar configurações

Chaves de API gratuitas

  • Groq (recomendado): https://console.groq.com → API Keys
  • Gemini: https://aistudio.google.com → Get API Key
  • OpenAI: https://platform.openai.com → API Keys

Banco Neon (opcional, gratuito)

  1. Acesse https://neon.tech → crie conta gratuita
  2. Crie um projeto e copie a Connection String
  3. Cole no app em ⚙️ Config. → URL do Neon
  4. Toque em Testar e criar tabelas

As tabelas são criadas automaticamente.

Se der erro de quota no EAS

Aguarde alguns minutos e tente novamente — é o limite do plano gratuito.
Ou tente o perfil production:

bash
npx eas build --platform android --profile production --non-interactive
