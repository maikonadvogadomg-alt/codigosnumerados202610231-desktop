📖 Guia — Como Montar seu PWA

🎯 Estratégia: Em vez de tentar fazer tudo de uma vez, vamos por partes. Cada funcionalidade vira um "módulo" independente. Depois juntamos.
Passo a Passo
  1. Separe os códigos por função — cada pedaço faz UMA coisa (importar PDF, gerar documento, salvar dados...)
  2. Cole cada pedaço como módulo — use a aba "Adicionar Módulo" e dê nome descritivo
  3. Teste individual — na aba Preview, veja se cada módulo funciona sozinho
  4. Monte o projeto — na aba "Montar", selecione os módulos e gere o HTML final
  5. Ajuste conflitos — se algo quebrar, traga aqui que te ajudo a resolver
Tipos de Módulo
🔧 Função/Lógica Código JavaScript puro (funções, cálculos, processamento de dados)
🎨 Visual/Interface HTML + CSS (botões, formulários, layout, cards)
📄 Bloco Completo HTML + CSS + JS juntos (componente inteiro que funciona sozinho)
💅 Apenas CSS Estilos visuais (tema, cores, fontes, animações)
📊 Dados/Templates Modelos de documentos, arrays de dados, configurações
Sobre o Banco de Dados (Neon)

⚠️ Importante: Um HTML puro no navegador NÃO consegue conectar direto no Neon (PostgreSQL). Precisa de um "servidor" no meio.

🟢 Alternativa que funciona sem servidor:

  • localStorage — salva no navegador (o que estamos usando aqui)
  • IndexedDB — banco mais robusto no navegador (suporta mais dados)
  • Exportar/Importar JSON — backup manual dos dados

🔵 Se quiser Neon no futuro: Precisará de um backend (Vercel Functions, Cloudflare Workers, ou Supabase que já dá tudo pronto).
