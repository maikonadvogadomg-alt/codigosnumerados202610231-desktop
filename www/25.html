📖 Manual de Uso

🎯 O que é o Cirurgião 3.0?

Uma ferramenta inteligente para importar, analisar, detectar problemas e editar código. Suporta múltiplos formatos (ZIP, TAR, HTML, JS, etc) e identifica automaticamente: bugs, dependências do Replit, APIs, funções, erros de sintaxe e mais.

📋 Formatos Suportados

  • Compactados: ZIP, TAR, TAZ (.tar.gz)
  • Código: HTML, JS, CSS, JSX, TSX, TS, JSON, TXT
  • Diretos: Cole código no campo "Ou Cole Diretamente"

🔍 Detecções Automáticas

  • BUG Erros, console.log, undefined
  • REPLIT Arquivos .replit, replit.nix
  • API Chamadas HTTP, fetch, axios
  • FUNCTION Funções e métodos

💡 Dicas

  • Use a busca para encontrar termos específicos
  • Clique em um arquivo para ver seu conteúdo completo
  • Use "IA Analyze" para análise automática
  • Salve notas para documentar problemas encontrados
  • Use "IA Reescrever" para melhorar o código
